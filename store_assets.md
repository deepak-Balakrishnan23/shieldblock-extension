# Chrome Web Store Listing Copy

## Short Description

AI-powered ad blocker that stops ads, trackers, annoyances, and sponsored content locally with zero data collection.

## Full Description

### Fast, private ad blocking

ShieldBlock AI combines Chrome's declarative network engine with cosmetic filtering, scriptlets, heuristics, and a local ML classifier to stop ads before they become distracting.

### What ShieldBlock AI blocks

- display ads
- video ad overlays and YouTube ad surfaces
- trackers and analytics beacons
- cookie banners and nuisance prompts
- sponsored and promoted feed items
- anti-adblock scripts on supported sites

### Why it is different

ShieldBlock AI uses layered blocking:

- network rules for core blocking
- main-world scriptlets for anti-adblock defeat
- cosmetic rules for leftover ad slots
- heuristic detection for native ads
- local ML scoring for borderline sponsored content

### Privacy first

ShieldBlock AI does not collect browsing data, does not require accounts, and does not send page content to remote servers. Filter processing and ad detection stay local in the browser.

### Power user controls

Use the popup and options page to:

- toggle protection instantly
- refresh filter lists
- allowlist a site
- pick and hide elements
- write custom ABP and cosmetic rules
- export and import settings

## Key Features

- Layered blocking engine with DNR, cosmetic filtering, scriptlets, heuristics, and local ML
- Zero data collection and no remote analytics
- Built-in YouTube ad surface suppression and SPA-aware behavior
- Custom rules, allowlist management, and element picker
- Live filter list pipeline with EasyList, EasyPrivacy, uBlock Filters, and AdGuard Base
